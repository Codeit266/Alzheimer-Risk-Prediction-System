# Alzheimer's Risk Prediction System

An AI-powered web application for early Alzheimer's risk prediction using speech analysis, Natural Language Processing (NLP), and Machine Learning. The system analyzes speech recordings and transcripts to estimate cognitive risk through a React.js frontend and Flask backend.

---

## Overview

This project combines speech processing, OpenAI Whisper, NLP, and a Random Forest classifier to assist in the early assessment of Alzheimer's disease. It extracts linguistic and acoustic features from speech and presents prediction results through an interactive web interface.

---

## Key Features

- Speech recording and transcript upload
- Audio preprocessing
- Speech transcription using OpenAI Whisper
- Feature extraction from speech
- Alzheimer's risk prediction using Random Forest
- Interactive result visualization with Chart.js
- React.js frontend with Flask REST API
